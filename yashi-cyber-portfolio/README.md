# YASHI.exe — Portfolio

A responsive neon/cyberpunk portfolio inspired by the supplied reference design.

## Run it
1. Download and extract the ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.
3. Edit the text, project descriptions, email address and skills in `index.html`.
4. Change colors and layout in `style.css`.
5. Replace `assets/hero-art.png` with your own artwork if desired.

## Before publishing
- Replace `your.email@example.com` with your real professional email.
- Update project links (`href="#contact"`) with your GitHub repositories or live demos.
- Keep project descriptions accurate and add real screenshots where possible.
- The Google Fonts import needs an internet connection; fallback fonts are included.
